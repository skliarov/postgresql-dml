Уяви собі звичайний зошит або електронну таблицю Excel у магазині техніки. У ньому є таблиця products (товари). Кожен стовпчик (колонка) — це характеристика товару (назва, ціна, залишок). А кожен рядок (запис) — це один конкретний товар на поличці.

DML (Data Manipulation Language) — це частина мови SQL, яка дозволяє виконувати 4 основні дії з даними:

  • INSERT — додати новий товар у таблицю;
  • SELECT — подивитися, які товари у нас є;
  • UPDATE — змінити ціну чи кількість існуючого товару;
  • DELETE — списати чи видалити товар.

Додаємо новий запис: оператор INSERT

💡 Життєва аналогія: Приїхала доставка!
Кур'єр привіз у магазин нові товари. Твоє завдання як комірника — записати новий рядок у журнал обліку: яку назву має товар, до якої категорії належить, скільки коштує та скільки штук приїхало.

Для додавання рядків у PostgreSQL використовується команда INSERT INTO.

⚠️ Золоте правило: Текстові дані (назви, категорії) у SQL обов'язково беруться в одинарні лапки (наприклад: 'Гаджети'), а числа записуються без лапок (наприклад: 1500).

INSERT INTO products (title, category, price, in_stock) VALUES ('Павербанк Pro', 'Гаджети', 1200, 15);

💡 Переконайся, що ти написав INSERT INTO products (title, category, price, in_stock) VALUES ('Бездротова миша', 'Аксесуари', 650, 20);. Текст обов'язково в однакових одинарних лапках!

UPDATE products SET price = 999 WHERE id = 1;

Базова структура оператора SELECT

💡 Життєва аналогія: Складаємо вітрину
У таблиці може бути 50 різних колонок (вага, колір, дата випуску, постачальник). Але для цінника покупцю потрібні лише дві речі: назва товару та його ціна. Оператор SELECT дозволяє вибрати тільки ті стовпчики, які потрібні.

Базовий синтаксис SELECT складається з двох слів:

Напиши SELECT-запит, який поверне тільки два стовпчики: назву товару (title) та кількість на складі (in_stock).
💡 Напиши: SELECT title, in_stock FROM products;. Обов'язково розділяй стовпчики комою!

Фільтрація даних: WHERE, AND, OR

🔒
🔒 Виконайте попередній крок, щоб відкрити цей модуль.
💡 Життєва аналогія: Фільтри на сайті Rozetka
Покупець каже: «Покажіть мені тільки навушники чи колонки, які коштують менше 2000 грн». Слово WHERE (де/де саме) дозволяє відсіяти зайві рядки за чіткими умовами.

Умови фільтрації створюються за допомогою операторів порівняння:

= (дорівнює), > (більше), < (менше), >=, <=, != (не дорівнює).

Щоб об'єднати кілька умов, використовують логічні оператори:

  • AND — мають виконуватися обидві умови одночасно.
  • OR — достатньо, щоб виконувалася хоча б одна з умов.
SELECT title, price, category FROM products WHERE category = 'Аудіо' AND price < 2000;
🎯 Завдання: Знайди доступні гаджети
Вибери всі стовпчики (SELECT *) для товарів, які коштують менше 3000 грн (price < 3000).
💡 Запит: SELECT * FROM products WHERE price < 3000;. Число 3000 пишеться без лапок!

Сортування результатів: ORDER BY

🔒
🔒 Виконайте попередній крок, щоб відкрити цей модуль.
💡 Життєва аналогія: Від дешевих до дорогих
Коли ми шукаємо товари в інтернеті, нам часто хочеться відсортувати їх: від найдешевшого до найдорожчого, або за рейтингом від А до Я. За це відповідає фраза ORDER BY (впорядкувати за).

Напрямок сортування задається двома чарівними словами:

  • ASC (Ascending) — за зростанням: від 1 до 9, або від А до Я (діє за замовчуванням);
  • DESC (Descending) — за спаданням: від 9 до 1, або від Я до А.
SELECT title, price FROM products ORDER BY price DESC;
🎯 Завдання: Знайди товари з найбільшим залишком
Вибери назву (title) та залишок (in_stock) усіх товарів, відсортувавши їх за стовпчиком in_stock за спаданням (від найбільшого до найменшого, тобто DESC).
💡 Запит: SELECT title, in_stock FROM products ORDER BY in_stock DESC;. Слово ORDER пишеться разом із BY через пробіл.

Розрахунки на льоту: Агрегатні функції

🔒
🔒 Виконайте попередній крок, щоб відкрити цей модуль.
💡 Життєва аналогія: Калькулятор бухгалтера
Замість того, щоб вручну перебирати 1000 рядків і рахувати на калькуляторі, база даних може сама за долю секунди сказати: скільки всього товарів, яка середня ціна або який товар найдорожчий.

5 головних функцій-рятівників у SQL:

  • COUNT(*) — підраховує кількість рядків;
  • SUM(price) — знаходить загальну суму значень стовпчика;
  • AVG(price) — обчислює середнє арифметичне (Average);
  • MIN(price) — знаходить найменше значення;
  • MAX(price) — знаходить найбільше значення.
SELECT COUNT(*) AS total_products, AVG(price) AS average_price, MAX(price) AS max_price FROM products;
🎯 Завдання: Підрахуй кількість та мінімальну ціну
Напиши запит, який порахує загальну кількість товарів через COUNT(*) та мінімальну ціну через MIN(price).
💡 Запит: SELECT COUNT(*), MIN(price) FROM products;. Обидві функції записуються через кому в списку SELECT!

Групування даних: GROUP BY

🔒
🔒 Виконайте попередній крок, щоб відкрити цей модуль.
💡 Життєва аналогія: Розкладаємо товари по коробках
Уяви, що ми розклали всі наші гаджети по окремих коробках за категоріями: в одній коробці — тільки 'Аудіо', у другій — 'Аксесуари', у третій — 'Ноутбуки'. І тепер ми рахуємо кількість або середню ціну для кожної окремої коробки!
📌 Залізне правило GROUP BY:
Якщо ти використовуєш GROUP BY category, то у списку SELECT ти маєш право писати тільки сам стовпчик групування (category) або агрегатні функції на зразок COUNT(*), AVG(price). Не можна писати звичайне поле title без агрегації, бо в одній категорії може бути 10 різних назв, і база не знатиме, яку саме показати!
SELECT category, COUNT(*) AS items_count FROM products GROUP BY category;
🎯 Завдання: Згрупуй товари за категорією
Виведи назву категорії (category) та порахуй кількість товарів (COUNT(*)) у кожній з них за допомогою GROUP BY category.
💡 Запит: SELECT category, COUNT(*) FROM products GROUP BY category;. Стовпчик після SELECT має збігатися зі стовпчиком після GROUP BY!

Фінальний квест: Аналітичний звіт шеф-адміна

🔒
🔒 Виконайте попередній крок, щоб відкрити цей модуль.
🏆 Перевірка навичок справжнього SQL-розробника
Директор коледжу та керівник магазину підійшли до тебе з реальним бізнес-завданням: «Нам потрібен зведений аналітичний звіт. Покажи категорії товарів, де є товари ціною від 1000 грн, виведи для кожної такої категорії її назву та середню ціну товарів, і відсортуй від найдорожчої категорії до дешевшої!».

У цьому запиті поєднуються майже всі конструкції, які ми вивчили:

SELECT category, AVG(price) FROM products WHERE price >= 1000 GROUP BY category ORDER BY AVG(price) DESC;

Порядок виконання в PostgreSQL:

  1. 1. FROM — беремо таблицю products;
  2. 2. WHERE — відфільтровуємо лише рядки з ціною від 1000;
  3. 3. GROUP BY — збиваємо залишок у групи за category;
  4. 4. SELECT — рахуємо середнє AVG(price);
  5. 5. ORDER BY — сортуємо результат за спаданням DESC.
🎯 Фінальне завдання: Напиши комплексний аналітичний запит
Виведи категорію (category) та середню ціну (AVG(price)) для товарів з ціною price >= 1000, згрупуй за category та відсортуй за AVG(price) DESC.
💡 Повний синтаксис: SELECT category, AVG(price) FROM products WHERE price >= 1000 GROUP BY category ORDER BY AVG(price) DESC;. Зверни увагу на правильний порядок слів: спочатку WHERE, потім GROUP BY, в кінці ORDER BY!

📖 Шпаргалка з DML у PostgreSQL

1. Вставка запису (INSERT)

Додає новий рядок. Текст беремо в одинарні лапки '...', числа без лапок.

INSERT INTO products (title, price) VALUES ('Мишка', 500);

2. Оновлення запису (UPDATE)

Змінює значення в існуючих рядках. Завжди пиши WHERE, інакше оновиться все!

UPDATE products SET price = 450 WHERE id = 1;

3. Видалення запису (DELETE)

Видаляє рядок за умовою. Без WHERE очистить усю таблицю!

DELETE FROM products WHERE id = 1;

4. Базовий вибір колонок (SELECT)

Вибирає потрібні стовпчики або всі через зірочку *.

SELECT title, price FROM products;

5. Фільтрація (WHERE, AND, OR)

Відсіює рядки за умовами порівняння: =, >, <, !=.

SELECT * FROM products WHERE price < 2000 AND in_stock > 5;

6. Сортування (ORDER BY)

ASC — за зростанням (за замовчуванням), DESC — за спаданням.

SELECT * FROM products ORDER BY price DESC;

7. Агрегатні функції (COUNT, AVG, SUM, MIN, MAX)

Обчислюють підсумки по всьому стовпчику таблиці.

SELECT COUNT(*), AVG(price), MAX(price) FROM products;

8. Групування (GROUP BY)

Об'єднує рядки з однаковими значеннями для розрахунку агрегатів по групах.

SELECT category, COUNT(*) FROM products GROUP BY category;
